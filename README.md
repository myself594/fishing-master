## 使用说明

### 环境要求
- Godot Engine 4.5.1

### 运行项目
1. 使用 Godot 4.5.1 打开 `project.godot`
2. 按 F5 运行项目

### 导出微信小程序
需要配合 [Godot工具箱](https://github.com/nicegamer/godot-wechat-mini-game) 进行转换

## 操作说明

### 钓鱼流程
1. **选择钓场** - 点击钓场卡片进入
2. **抛竿** - 长按屏幕蓄力，松手抛出
3. **等待** - 观察浮漂，等待鱼咬钩
4. **提竿** - 浮漂下沉时快速点击屏幕
5. **遛鱼** - 按住屏幕拉鱼，松开休息
   - 注意：张力过高会断线！
6. **收获** - 成功后获得金币和经验

### 技巧
- 抛竿力度越大，落点越远，大鱼概率越高
- 咬钩后0.5-0.8秒内提竿为「完美」，经验+50%
- 遛鱼时注意张力，适时松手休息

## 美术说明

当前版本使用**色块**代替美术资源：
- 背景：ColorRect + 渐变色
- 浮漂：红色矩形
- 鱼类：根据数据配置的颜色矩形
- 装备：根据品质颜色的矩形

后续可替换为正式美术资源。
